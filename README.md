# Grand — Virtual Piano

Zamonaviy, yengil va professional 88-klavishli virtual akustik royal platformasi.

## Imkoniyatlar

- **100% Haqiqiy Akustik Royal**: Professional studiyada yozib olingan haqiqiy Yamaha C5 Grand Concert audio namunalari.
- **Kompakt Musiqiy HUD**: Skrolsiz, avtomatik markazlanuvchi yagona qatorli teleprompter lentasi (`text-2xl` va `text-3xl`).
- **Boyitilgan Notalar Kutubxonasi**: O'zbek xalq kuylari (_Tanovar_, _Bahor valsi_, _Munojot_, _Andijon polkasi_) va jahon durdonalari (_One Summer's Day_, _Golden Hour_, _Moonlight Sonata_, _Für Elise_, _River Flows in You_).
- **Web MIDI & Yozib olish**: Tashqi MIDI sintezator/klaviatura ulash, WAV va MIDI formatlarda yozib olish.
- **Auto-Play & Mashq**: Har bir kuy uchun avtomatik ijro va qadamma-qadam kutish rejimi.

## Ishga tushirish (Local Development)

```bash
# Bog'liqliklarni o'rnatish
npm install

# Dasturni ishlab chiqish rejimida ishga tushirish
npm run dev

# Testlarni yurgazish
npm run test

# Kodni formatlash va lint qilish
npm run format
npm run lint

# Ishlab chiqarish (Production) uchun yig'ish
npm run build
```
